\section{实验原理}

混频器主要应用于通信系统的发射和接收机中。混频是频谱的线性搬移，输出信号与输入信号相比，只是载波频率发生了变化，频谱结构没有变化，输出信号的波形也没有变化。实现混频的基本方法是将两个输入信号相乘。这可以通过器件的非线性特性实现，这些器件主要有二极管、三极管和场效应管。在发射机中使用上混频，本振信号将已调制的中频信号搬移到射频频段。在接收机中使用下混频，通过混频，将接收到的射频信号搬移到中频频段。

设混频器的本振输入信号为：
\begin{equation}
v_{LO}(t) = V_{LO} \cos \omega_{LO} t
\tag{3.5.1}
\end{equation}

混频器的另外一路信号为：
\begin{equation}
v_i = V_i \cos \omega_i t
\tag{3.5.2}
\end{equation}

两路信号相乘，得到的输出信号为：
\begin{equation}
v_o = \frac{1}{2} V_{LO} V_i \left[ \cos(\omega_i + \omega_{LO})t + \cos(\omega_i - \omega_{LO})t \right]
\tag{3.5.3}
\end{equation}

对于发射机系统中的上混频，是把差频滤除，保留和频信号；对于接收机系统中的下混频，是把和频滤除，保留差频信号。

\subsection{混频器的主要性能指标}
\begin{enumerate}
	\item 混频增益
	\item 线性度
	\item 隔离度
\end{enumerate}

\subsection{二极管双平衡混频器}
在大信号的作用下，二极管的伏安特性可以看作是从原点出发，斜率为 $g_D$ 的直线，二极管可以看成是受大信号控制的单向开关。若二极管两端的电压为 $v_D(t)$，其伏安特性为：
\begin{equation}
i_D = g_D S_1(\omega t) v_D(t)
\tag{3.5.5}
\end{equation}

假设在二极管两端所加的电压为 $v_D(t) = v_{LO}(t) + v_i(t)$，其中 $v_{LO}(t) = V_{LO} \cos \omega_{LO} t$ 是本振信号，为大信号；$v_i(t) = V_i \cos \omega_i t$ 是小信号。

开关函数 $S_1(\omega_{LO} t) = \frac{2}{\pi} \cos \omega_{LO} t - \frac{2}{3\pi} \cos \omega_{LO} t + \frac{2}{5\pi} \cos \omega_{LO} t - \cdots$。因此，作为混频器时，由式 (3.5.5) 可以得到本振信号和输入小信号的和频 $\omega_{LO} + \omega_i$ 和差频 $\omega_{LO} - \omega_i$ 信号，通过滤波器即可获得所需的混频信号。这种简单的二极管混频电路，输出信号中的组合频率分量比较多，在实际应用中常使用二极管双平衡混频器，电路如下图所示。

\subsection{吉尔伯特双平衡混频器}
吉尔伯特双平衡混频器如下图所示，本振信号输入部分是两个差分管对，射频口为一个差分管对。通常，本振口送大信号，$Q_1$、$Q_2$、$Q_3$、$Q_4$ 组成开关控制电路。射频口送小信号，电路工作在线性放大区。它与单管或单平衡混频器相比的优点是：各个端口之间的隔离性能很好，线性范围比较大。

\subsubsection{和频提取过程}
\begin{itemize}
\item 本振大信号 $v_{LO}(t) = V_{LO} \cos \omega_{LO} t$ 从中心抽头加入；
\item 射频小信号 $v_i(t) = V_i \cos \omega_i t$ 从一侧输入；
\item 输出负载 $R_L$ 接于另一侧，获取差动电流。
\end{itemize}
在本振正半周，$D_1, D_2$ 导通；负半周，$D_3, D_4$ 导通。因此，流过各二极管的电流可表示为：

\begin{align}
i_{D2} - i_{D1} &= \frac{-2v_i(t)}{2R_s + R_D} S_1(\omega_{LO} t) \\
i_{D3} - i_{D4} &= \frac{-2v_i(t)}{2R_s + R_D} S_1(\omega_{LO} t + \pi)
\end{align}

其中，$S_1(\cdot)$ 为本振信号控制下的单向开关函数。

\paragraph{输出电流表达式}~\\

在整个本振周期内，流经输出负载的净电流为：

\begin{equation}
i = (i_{D3} - i_{D4}) - (i_{D2} - i_{D1}) = \frac{2v_i(t)}{2R_s + R_D} S_2(\omega_{LO} t)
\tag{3.5.6}
\end{equation}

式中，$S_2(\omega_{LO} t)$ 为双向开关函数，其傅里叶级数展开为：

\begin{equation}
S_2(\omega_{LO} t) = \frac{4}{\pi} \cos \omega_{LO} t - \frac{4}{3\pi} \cos 3\omega_{LO} t + \frac{4}{5\pi} \cos 5\omega_{LO} t - \cdots
\end{equation}

\paragraph{和频分量的产生}~\\

将输入信号 $v_i(t) = V_i \cos \omega_i t$ 代入式 (3.5.6)，得：

\begin{align}
i(t) &= \frac{2V_i \cos \omega_i t}{2R_s + R_D} \cdot \left( \frac{4}{\pi} \cos \omega_{LO} t - \frac{4}{3\pi} \cos 3\omega_{LO} t + \cdots \right) \\
&= \underbrace{\frac{8V_i}{\pi(2R_s + R_D)} \cos \omega_i t \cos \omega_{LO} t}_{\text{主项}} + \text{高次谐波项}
\end{align}

利用三角恒等式 $\cos A \cos B = \frac{1}{2} [\cos(A+B) + \cos(A-B)]$，主项可展开为：

\begin{equation}
i_{\text{main}}(t) = \frac{4V_i}{\pi(2R_s + R_D)} \left[ \cos((\omega_{LO} + \omega_i)t) + \cos((\omega_{LO} - \omega_i)t) \right]
\end{equation}

由此可见，输出电流中包含：
\begin{itemize}
    \item 和频分量：$\omega_{LO} + \omega_i$
    \item 差频分量：$\omega_{LO} - \omega_i$
    \item 高次谐波组合：如 $3\omega_{LO} \pm \omega_i$ 等（幅度较小）
\end{itemize}

\section{思考题}
\begin{enumerate}[label=(\arabic*), leftmargin=*]

    \item \textbf{混频器的主要性能指标有哪些？}

    混频器是射频系统中的关键非线性器件，其主要性能指标包括：

    \begin{itemize}
        \item \textbf{变频增益（Conversion Gain）}：输出中频信号功率与输入射频信号功率之比（单位：dB），反映信号放大能力。
        \item \textbf{噪声系数（Noise Figure, NF）}：衡量混频器引入额外噪声的程度，越低越好。
        \item \textbf{1dB 压缩点（$P_{1\mathrm{dB}}$）}：增益比小信号线性增益下降 1 dB 时对应的输入功率，表征线性动态范围上限。
        \item \textbf{三阶互调截点（IP3）}：衡量非线性失真程度，越高表示抗干扰能力越强。
        \item \textbf{端口隔离度（Isolation）}：如 LO-RF、LO-IF、RF-IF 之间的隔离度，防止本振泄漏和信号串扰。
        \item \textbf{带宽（Bandwidth）}：支持的工作频率范围，包括 RF 带宽和 IF 带宽。
        \item \textbf{本振驱动功率（LO Drive Level）}：使混频器正常工作所需的本振功率，影响功耗和设计复杂度。
    \end{itemize}

    \item \textbf{吉尔伯特双平衡混频器与二极管双平衡混频器相比，优势有哪些？}

    吉尔伯特单元（Gilbert Cell）是一种基于晶体管的有源混频器，相较于无源二极管双平衡混频器，具有以下显著优势：

    \begin{itemize}
        \item \textbf{提供变频增益}：吉尔伯特混频器为有源结构，可实现正增益（通常 5–20 dB），而二极管混频器通常为损耗型（增益 < 0 dB）。
        \item \textbf{更高的端口隔离度}：由于对称差分结构和电流开关机制，LO-RF、LO-IF 隔离度更高，减少本振泄漏。
        \item \textbf{更好的线性度}：通过偏置控制和负反馈技术，可优化 IP3 和 $P_{1\mathrm{dB}}$，适用于高动态范围系统。
        \item \textbf{易于集成}：采用 CMOS 或 BiCMOS 工艺，便于与基带电路单片集成，适合现代通信芯片设计。
        \item \textbf{可调增益}：可通过调节尾电流或负载电阻实现增益控制，适应不同应用场景。
    \end{itemize}

    \item \textbf{混频器变频增益主要受哪些因素的影响？}

    变频增益是混频器核心参数，其大小受多种因素影响：

    \begin{itemize}
        \item \textbf{本振功率（LO Power）}：对于无源混频器（如二极管），增益随 LO 功率增加而提升直至饱和；对于有源混频器（如 Gilbert），需足够 LO 功率驱动开关管完全导通/截止。
        \item \textbf{晶体管跨导（$g_m$）}：在有源混频器中，增益正比于输入级晶体管的跨导，受偏置电流和器件尺寸影响。
        \item \textbf{负载阻抗}：输出端负载电阻或 LC 谐振回路 Q 值直接影响电压增益。
        \item \textbf{频率响应}：随着工作频率升高，寄生电容（如 $C_{gs}$、$C_{gd}$）导致增益滚降。
        \item \textbf{温度与工艺偏差}：半导体参数随温度变化，制造过程中的阈值电压、迁移率波动也会影响增益稳定性。
        \item \textbf{输入匹配网络}：若 RF 输入未良好匹配至 50 Ω，部分信号反射会导致有效增益降低。
    \end{itemize}
\end{enumerate}
