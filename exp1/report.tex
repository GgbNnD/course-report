\section{实验目的}

\begin{enumerate}
	\item 掌握小信号调谐放大器的工作原理。
	\item 掌握频谱分析仪的基本使用方法。
	\item 掌握调谐放大器电压增益、通频带及选择性的定义、测试及计算方法。
\end{enumerate}

\section{实验原理}

小信号调谐放大器广泛用作高频和中频放大器，特别是用在通信接收端的前端电路，其主要目的就是实现对高频小信号的放大。谐振放大器的负载是采用谐振回路，具有放大、滤波和选频的作用。作为负载的谐振回路，通常采用LC组成的并联谐振电路。由于LC并联谐振回路的阻抗是随着频率变化而变化，并联谐振回路在谐振频率处呈现纯阻，并达到最大值。即放大器在回路谐振频率上将具有最大的电压增益。若偏离谐振频率，增益将减小。

小信号是相对而言的，信号电平处在放大器的线性范围内，就可以认为是小信号。

\subsection{小信号调谐放大器的主要性能指标}

小信号调谐放大器的幅频特性如图3.1.1所示。

\begin{figure}[h]
	\centering
	\includegraphics[width=0.6\textwidth]{fig3_1_1.png} % 请替换为实际图片路径
\end{figure}

衡量小信号调谐放大器的主要性能指标包括以下几个方面：

\begin{enumerate}
	\item 谐振频率（\(f_0\)）：放大器调谐回路谐振时所对应的频率 \(f_0\) 称为放大器的谐振频率。
	\item 谐振电压增益（\(A_{V0}\)）：放大器处在谐振频率时，所对应的电压放大倍数 \(A_{V0}\) 称为调谐放大器的谐振电压增益。其表达式为：
	      \[
		      A_{V0} = \frac{V_o}{V_i}, \quad \text{或} \quad A_{V0} = 20\log\left(\frac{V_o}{V_i}\right) \quad \text{(dB)}
	      \]
	      也可以用功率增益表示：
	      \[
		      A_{P0} = \frac{P_o}{P_i}, \quad \text{或} \quad A_{P0} = 10\log\left(\frac{P_o}{P_i}\right) \quad \text{(dB)}
	      \]
	\item 通频带（\(BW_{3dB}\)）：电压增益下降到谐振电压增益的0.707倍（-3dB）时所对应的上下限频率之差称为放大器的通频带带宽 \(BW\)，表达式为：
	      \[
		      BW = f_H - f_L = 2\Delta f_{0.7} = \frac{f_0}{Q_L}
	      \]
	      式中 \(Q_L\) 为谐振回路的有载品质因数。
	\item 增益带宽积（\(A_{V0} \cdot BW_{3dB}\)）：通常可以认为是一个常数，放大器的总通频带宽度随着放大级数的增加而变窄，增益与带宽是一对矛盾。
	\item 选择性：定义矩形系数 \(K_{V0.1}\) 为电压增益下降到谐振时电压增益的0.1倍（-20dB）时对应的带宽与3dB带宽之比：
	      \[
		      K_{v0.1} = \frac{BW_{20dB}}{BW_{3dB}}
	      \]
	      矩形系数越接近1，选择性越好。
\end{enumerate}

\subsection{单调谐放大器}

图3.1.2是典型的单调谐回路小信号放大器。其交流等效电路及y参数等效电路如图3.1.3（b）、（c）所示。
\begin{center}
	\centering
	\includegraphics[width=0.8\textwidth]{fig3_1_23.png} % 请替换为实际图片路径
\end{center}
电压增益表达式为：
\[
	\dot{A}_V = \frac{-p_1 p_2 y_{fe}}{g_{\Sigma} + j\omega C_{\Sigma} + \frac{1}{j\omega L}} \approx \frac{-p_1 p_2 y_{fe}}{g_{\Sigma}\left[1 + j\frac{2Q_L \Delta f}{f_0}\right]}
\]
其中：
\[
	f_0 = \frac{1}{2\pi\sqrt{LC_{\Sigma}}}, \quad Q_L = \frac{\omega_0 C_{\Sigma}}{g_{\Sigma}}, \quad BW_{3dB} = \frac{f_0}{Q_L}
\]
进一步可得：
\[
	A_{V0} \cdot BW = \frac{-p_1 p_2 y_{fe}}{2\pi C_{\Sigma}}
\]
即增益带宽积为常数。

单调谐放大器的矩形系数为：
\[
	K_{V0.1} = \frac{BW_{20dB}}{BW_{3dB}} = \sqrt{10^2 - 1} \approx 9.95
\]
选择性较差。

\subsection{调谐放大器的级联与双调谐放大器}

多级级联时，总增益为各级增益乘积，总通频带为单级通频带的 \(\sqrt{\frac{1}{2^n} - 1}\) 倍。双调谐放大器具有频带宽、选择性好的优点。

双调谐放大器在临界耦合时的通频带为：
\[
	BW = 2\Delta f_{0.7} = \frac{\sqrt{2} f_0}{Q_L}
\]

\section{数据分析}
\subsection{静态工作点对谐振放大器的影响分析}
根据表 \ref{tab:3.1.1} 的数据，当晶体管的静态工作电流由 $1\mathrm{mA}$ 增加到 $5\mathrm{mA}$ 时，输出功率由 $-6.31\mathrm{dBm}$ 增加到 $6.41\mathrm{dBm}$，谐振增益由 $13.69\mathrm{dB}$ 显著提高到 $26.41\mathrm{dB}$。这说明晶体管的交流放大倍数（跨导 $g_m$）随着静态工作电流 $I_C$ 的增大而增大，从而使得整体谐振增益增加。
同时，从表格数据可以看出，在不同工作电流下，3dB带宽维持在 $1633\mathrm{kHz}$ 到 $1667\mathrm{kHz}$ 之间，变化非常微小。这说明改变晶体管的静态工作点主要影响放大器的增益，而对回路的等效品质因数 $Q_L$ 和总电容 $C_{\Sigma}$ 影响较小，因而对通频带带宽的影响不明显。

\subsection{单调谐与双调谐耦合状态特性对比分析}
根据前述的特性测量数据以及三种耦合状态的特性曲线：
\begin{itemize}
	\item \textbf{谐振增益}：弱耦合 ($23.5\mathrm{dB}$) $>$ 单调谐 ($23.04\mathrm{dB}$) $\approx$ 临界耦合 ($22.76\mathrm{dB}$) $>$ 强耦合 ($22.24\mathrm{dB}$)。
	\item \textbf{通频带}：强耦合 ($1.867\mathrm{MHz}$) $>$ 单调谐 ($1.567\mathrm{MHz}$) $>$ 临界耦合 ($1.2\mathrm{MHz}$) $>$ 弱耦合 ($0.767\mathrm{MHz}$)。强耦合时频带最宽，但曲线顶部会出现双峰现象；弱耦合时频带最窄，呈单峰。
	\item \textbf{选择性（矩形系数）}：强耦合 ($2.642$) $<$ 临界耦合 ($3.167$) $<$ 弱耦合 ($3.999$) $\ll$ 单调谐 ($10.062$)。矩形系数越小，接近于1，选择性越好。
\end{itemize}
综合对比可见，双调谐放大器相比于单调谐放大器，在矩形系数上有大幅度的下降（从 $10$ 左右降至 $2.6 \sim 4.0$ 之间），即选择性得到了极大的改善。在临界耦合状态下，可以在增益、通频带和选择性之间取得较好的折中，且频带顶部较为平坦。

\section{思考题}
\paragraph{高频小信号放大器的主要技术指标有哪些？}~\\
高频小信号放大器的主要技术指标包括：
\begin{enumerate}
	\item 谐振频率（$f_0$）；
	\item 谐振电压增益（$A_{V0}$）或功率增益（$A_{P0}$）；
	\item 通频带（$BW_{3dB}$），即电压增益下降到0.707倍时的频带宽度；
	\item 增益带宽积（$A_{V0} \cdot BW_{3dB}$），通常近似为常数；
	\item 选择性，通常用矩形系数 $K_{V0.1}$ （20dB带宽与3dB带宽之比）来衡量，矩形系数越接近1，选择性越好。
\end{enumerate}

\paragraph{单级单调谐放大器的电压增益与那些因素有关？当谐振回路中的并联电阻R变化时，增益及带宽将怎样变化？当谐振放大器的静态工作点变化时，增益及带宽将怎样变化？}~\\
（1）单级单调谐放大器的电压增益主要与晶体管的跨导（$y_{fe}$）、输入和输出端的接入系数（$p_1, p_2$）以及谐振回路的总等效并联导纳（$g_{\Sigma}$，即总并联电阻 $R_{\Sigma}$ 的倒数）有关。\\
（2）当谐振回路中的并联电阻 $R$ 增大时，电压增益会增大（增益与并联电阻成正比）。同时，根据通频带公式 $BW = \frac{1}{2\pi R_{\Sigma} C_{\Sigma}}$，并联电阻 $R$ 的增大会导致通频带带宽变窄。\\
（3）当谐振放大器的静态工作点变化时（例如静态电流 $I_C$ 增大），晶体管的跨导 $g_m$ 增大，从而使得谐振增益显著增加。而静态工作点的改变对晶体管的结电容和输出阻抗影响较小，因此回路的总等效电容和总电阻变化不大，通频带带宽基本保持不变。

\paragraph{回路的谐振频率和那些参数有关？如何判断谐振回路处于谐振状态？}~\\
（1）回路的谐振频率主要与谐振回路的等效电感 $L$ 和总等效电容 $C_{\Sigma}$ 有关，计算公式为 $f_0 = \frac{1}{2\pi\sqrt{LC_{\Sigma}}}$。通过调节电感量或电容量即可改变谐振频率。\\
（2）判断谐振回路是否处于谐振状态的方法：
\begin{itemize}
	\item 使用频谱分析仪观察幅频特性曲线，当输出信号幅度（或增益）达到最大峰值时，对应的频率即为谐振频率，此时回路处于谐振状态。
	\item 理论上，谐振时回路呈现纯电阻特性，即输入电压与电流的相位差为0。
\end{itemize}
