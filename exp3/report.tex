\section{实验目的}
\begin{enumerate}
	\item 掌握 LC 振荡器、晶体振荡器和压控振荡器的工作原理和电路结构

	\item 对电路主要参数进行测量分析
\end{enumerate}

\section{实验原理}
振荡器是一种不需要外部激励，就能将直流电源提供的功率转换成具有一定频率和振幅的信号输出的装置。振荡器一般由晶体管、场效应管等有源器件和具有选频能力的网络组成。

按工作原理可分为反馈型和负阻型振荡器；按选频网络可分为LC振荡器、晶体振荡器和RC振荡器等。
\subsection{主要性能指标}
\begin{enumerate}
	\item 相位噪声
	\item 谐波失真
	\item 其他性能指标
	      \begin{itemize}
		      \item 自由震荡频率
		      \item 频率变化范围
		      \item 线性度
		      \item 压控灵敏度
	      \end{itemize}
\end{enumerate}

\subsection{反馈型振荡器的工作原理}
反馈型振荡器由放大器和一个正反馈电路构成，原理框图如图所示。放大器是以选频电路作为负载的调谐放大器，反馈电路由无源器件组成。其中，$ A(j\omega) $是放大器的电压增益，$ F(j\omega) $是反馈系数。
\begin{center}
	\includegraphics[width = 0.6\textwidth]{fig1}
\end{center}
反馈放大器的增益为：
\begin{equation}
	A_{f}(j\omega)=\frac{A(j\omega)}{1 - A(j\omega)F(j\omega)}
\end{equation}

反馈振荡器的环路增益为：
\begin{equation}
	T(j\omega)=A(j\omega)F(j\omega)
\end{equation}

\subsection{LC三点式振荡器}
三点式振荡器采用 LC 振荡回路部分接入的形式，有电感三点式振荡器，电容三点式振荡器，改进型的电容三点式振荡器。图 3.3.3 (a) 是电容三点式振荡器的电路图，图 3.3.3 (b) 是它的交流等效电路。

\end{center}

\subsection{晶体振荡器}
石英晶体的等效电路如图所示。石英晶体的振荡频率由石英晶体和负载电容$ C_L $（电路中等效为与晶体并联的电容）确定，可以通过改变$ C_L $的值来微调振荡频率，但调节范围很小。晶体振荡器的频率：
\begin{equation}
	f = \frac{1}{2\pi \sqrt{L_q \cdot \frac{C_q (C_o + C_L)}{C_q + (C_o + C_L)}}}
	\label{eq:3.3.7}
\end{equation}
\begin{center}
	\includegraphics[width = 0.6\textwidth]{fig3}
\end{center}

\subsection{压控振荡器}

振荡器频率由电压控制，作线性变化，即为压控振荡器。通常，将变容二极管作为可变电容，接入LC振荡器中，构成压控振荡器。变容二极管在反向偏置条件下，它的势垒电容随外加电压变化，电容 $C_j = C_o / (1 + u/u_\varphi)^\gamma$，$C_o$ 是变容二极管偏置为零时的结电容，$u_\varphi$ 是变容二极管PN结的势垒电位差，$\gamma$ 是结电容变化指数，与制造工艺有关。

\subsection{FM\_FSK 调制}

FM调频产生的方法主要有两种，直接调频和间接调频。直接调频就是调制信号直接作用于振荡器，使振荡频率随调制信号变化。对于LC振荡电路，由调制信号控制其中的一个电抗元件，使它随调制信号变化，则振荡频率将受控与调制信号，达到调频的目的。在高频电路中，经常由变容二极管来实现。

\section{实验电路分析}
实验电路如图3.3.8所示。SW$_2$为振荡器选择开关，将SW$_2$设成“1000”，就构成了一个改进型的电容三点式振荡器，通过调节电容C$_8$，可以改变振荡频率；将SW$_2$设成“0100”，电容三点式振荡器中的电感用石英晶体代替，就构成并联型石英晶体振荡电路，电容C$_6$、C$_7$、C$_{10}$、C$_8$构成的等效电容称为晶体的负载电容C$_L$。

将SW$_2$的第一位开关接通接通，在构成改进型电容三点式振荡器的基础上，再接通第三位或者第四位开关（即设为“1010”或“1001”），将变容二极管接入电路中，就构成压控振荡器。改变滑动变阻器WR$_2$的阻值，变容二极管上的直流电压也随之改变，就可以改变振荡频率。

在压控振荡电路连接方式下，音频调制信号可由JP2端口接入，与来自WR$_2$的静态电压通过电阻网络叠加后加到变容二极管，则振荡频率将受控于调制信号，达到调频的目的。若调制信号是正弦信号，则为FM调制；若调制信号是脉冲信号，则为FSK调制。

实验电路中，振荡电路的静态工作点将影响电路的工作状态，可通过WR$_1$调整。Q$_2$及外围的电阻器件构成了跟随电路，降低了振荡电路的输出阻抗，同时避免负载对于振荡电路的影响。通过调节WR$_4$还可调整输出信号幅度。

\section{思考题}
\begin{enumerate}
	\item \textbf{为什么振荡器起振后的直流工作点电流不同于起振前的静态工作点电流？}

	      答：振荡器起振前，电路处于小信号线性状态，工作点为静态工作点；起振后，随着振幅不断增大，晶体管等有源器件逐渐进入大信号非线性工作状态。由于器件的非线性特性，在大信号激励下会产生整流效应，使其电流的直流平均分量发生改变，因此起振后的直流工作点电流会偏离起振前的静态电流。

	\item \textbf{为什么反馈系数要选取 F=1/2-1/8,过大，过小有什么不好？}

	      答：反馈系数$F$的大小直接影响振荡器的起振条件和输出性能。如果$F$过小，导致环路增益不够，可能无法满足起振条件，或输出信号幅度很小。如果$F$过大，虽然容易起振，但会加深晶体管的非线性失真，导致输出波形谐波分量增加；同时，较大的反馈系数会使放大器的输入阻抗对谐振回路的影响变大，降低谐振回路的有载品质因数($Q$值)，从而使选频性能变差，频率稳定性下降。

	\item \textbf{对于 LC 电路，为什么当静态电流发生变化时，其振荡频率会发生变化？}

	      答：在LC振荡电路中，晶体管等有源器件的极间电容（如集电结电容、发射结电容等）与静态电流（直流工作点）密切相关。当静态电流发生变化时，这些极间电容的值也会发生改变。由于这些极间电容往往等效并联或串联在LC谐振回路中，它们的改变会引起谐振回路总电容的变化，进而导致LC电路的振荡频率发生改变。
\end{enumerate}
